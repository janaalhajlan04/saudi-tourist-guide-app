# Saudi Tourist Guide App

A Flutter mobile application designed to help users discover popular tourist attractions and landmarks across Saudi Arabia through a simple and intuitive interface.

## Overview

The application provides information about various tourist destinations and allows users to explore locations, search for attractions, and view destination details.

## Features

* Browse tourist attractions
* Search for destinations
* View attraction information
* Clean and user-friendly interface
* Multi-screen navigation

## Technologies

* Flutter
* Dart
